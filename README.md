# 🎯 ロト6予測ラボ

ロト6の過去当選番号を統計分析し、5つの異なる戦略で予想番号を自動生成するブラウザアプリです。
サーバー不要で、GitHub Pages でそのまま公開できます。

> **⚠️ 免責事項**: ロト6は完全にランダムな抽選です。過去の統計的傾向が将来の結果を予測する根拠にはなりません。本アプリは統計分析に基づく参考値を生成するもので、当選を保証するものではありません。宝くじの購入は自己責任で行ってください。

## 使い方（3ステップ）

1. **アクセス** — ブラウザでアプリを開く
2. **生成** — 「予想を生成する」ボタンをタップ → 5通りの予想番号が表示
3. **結果追加** — 抽選後に結果を追加すると自動検証＋自動学習で次回の精度が向上

## 主な機能

### 📊 5つの予想戦略
| 戦略 | 説明 |
|------|------|
| ホット | 直近50回の出現頻度上位＋トレンド重視 |
| コールド | 出現頻度が平均以下、平均回帰を狙う |
| 出遅れ | 長期間出現していない番号を重視 |
| バランス | 奇偶バランス・番号帯分散・合計値を最適化 |
| 統合AI | 全分析の加重平均（自動学習で精度向上） |

### 📈 統計分析
- 出現頻度チャート（ホット/コールド番号のハイライト）
- 番号帯分布（円グラフ）
- 奇数/偶数パターン分析
- 合計値ヒストグラム
- 出遅れ番号ランキング
- 番号ペアの相関分析
- 月曜 vs 木曜の曜日別傾向

### 🧠 自動学習エンジン
- 検証のたびに各戦略の成績を自動分析
- 成績の良い戦略の重みを自動で増加
- 学習率0.1で急激な変動を防止
- 学習履歴の可視化

### 📱 モバイル対応
- モバイルファースト設計
- PWA対応（ホーム画面に追加可能、オフライン動作）
- タッチ操作に最適化されたUI
- ダーク/ライトテーマ切替

## ホーム画面への追加

### iOS Safari
1. サイトを開く
2. 共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」を選択

### Android Chrome
1. サイトを開く
2. メニュー（⋮）をタップ
3. 「ホーム画面に追加」を選択

## データの追加方法

1. 「履歴」タブを開く
2. 「＋ 結果を追加」ボタンをタップ
3. 回号・日付・本数字6個・ボーナス数字を入力
4. 保存 → 未検証の予想があれば自動検証＋自動学習が実行

## 自動学習の仕組み

1. 予想を生成（5つの戦略）
2. 抽選後に結果を追加
3. 自動検証: 予想と実際の結果を照合
4. 自動学習: 各戦略の成績を分析し、統合AI戦略の重みパラメータを調整
5. 次回の予想に調整後の重みが反映される
6. このサイクルを繰り返すことで精度が向上

学習パラメータ:
- 学習率: 0.1（1回の調整で最大10%の変動）
- 最低サンプル数: 3回の検証データ
- 各パラメータの重み: 5%〜50%の範囲

## 技術仕様

- **フロントエンド**: HTML5 + CSS3 + Vanilla JavaScript
- **グラフ描画**: Chart.js (CDN)
- **フォント**: Noto Sans JP + JetBrains Mono (Google Fonts)
- **データ保存**: localStorage
- **PWA**: Service Worker + Web App Manifest
- **内蔵データ**: 210回分の過去当選番号

## GitHub Pages でのデプロイ

1. リポジトリの Settings → Pages
2. Source: Deploy from a branch
3. Branch: main, / (root)
4. Save → 数分後にアクセス可能
