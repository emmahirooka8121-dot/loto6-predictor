## 技術・デザイン
- フレームワーク不使用の静的サイト（HTML5 / CSS3 / Vanilla JS）
- レスポンシブデザイン（モバイルファースト）
- 日本語フォント：Google Fonts「Noto Sans JP」
- テーマカラー：ひまわりイエロー #FFC93C を中心とした温かい配色
- 本文16px以上・十分なコントラストで高齢の閲覧者にも配慮
- スマホでは画面下部に「電話をかける」固定ボタン（tel:リンク）を全ページ表示
- SEO対策（title / meta description / OGP / LocalBusinessのJSON-LD）

## Cloudflare Pages での公開
1. このリポジトリを Cloudflare Pages に接続（またはフォルダを直接アップロード）
2. ビルドコマンド：**なし**（静的サイトのため不要）
3. 出力ディレクトリ：**ルート（/）**
4. `index.html` がルート直下にあるため、そのまま公開されます
