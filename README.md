# ロト6 AI予測ラボ v3

ロト6の過去当選番号を統計分析し、7つのAIアルゴリズムを統合して予想番号を自動生成するブラウザアプリです。
サーバー不要で、GitHub Pages でそのまま公開できます。

> **免責事項**: ロト6は完全にランダムな抽選です。本アプリは統計的な傾向とAIアルゴリズムに基づく参考値を生成するもので、当選を保証するものではありません。宝くじの購入は自己責任でお願いいたします。

## 搭載AIアルゴリズム

| アルゴリズム | 説明 |
|---|---|
| モンテカルロシミュレーション | 重み付きランダムサンプリング（最大20万回試行） |
| 遺伝的アルゴリズム | トーナメント選択・交叉・適応的突然変異・多様性注入 |
| 焼きなまし法 | 局所最適解を脱出し広い解空間を探索 |
| エントロピー最適化 | 番号の情報量の多様性を最大化 |
| 相関ネットワーク | ペア＋トリプレットの同時出現パターン活用 |
| トレンド追従 | 温冷サイクル検出＋直近トレンド分析 |
| 出遅れ回帰 | 出現周期のポアソン分布近似 |

## fitness関数（12要素の複合スコアリング）

W1: 出現頻度 / W2: 出遅れ度 / W3: エントロピー / W4: 奇偶バランス /
W5: 合計値バランス / W6: 分散 / W7: 番号帯 / W8: ペア相関 /
W9: トレンド / W10: 曜日傾向 / W11: 出現周期 / W12: トリプレット

## 機能一覧

- **予想生成**: 5通りの戦略別予想（ポートフォリオ最適化で重複最小化）
- **確信度スコア**: 各予想の信頼度を0-100%で表示
- **スケジューラー**: 抽選前日正午に自動生成＋ロック機能
- **統計分析**: 12種類の分析＋ヒートマップ＋Chart.jsグラフ
- **的中検証**: 自動検証＋等級判定（1等〜5等）
- **自動学習**: 検証結果からW1〜W12の重みを自動調整
- **バックテスト**: 過去データでアルゴリズムの有効性をシミュレーション
- **マークシート表示**: 実際のロト6マークシートに近いビジュアル
- **ワンタップコピー**: 予想番号をクリップボードにコピー
- **QRコードデータ同期**: 端末間のデータ転送
- **PWA対応**: オフライン動作、ホーム画面追加可能

## 使い方

### 基本サイクル

1. **予測を生成** ボタンで5通りの予想番号を生成
2. 抽選後、**履歴タブ** で結果を追加（手動 or 自動取得トライ）
3. **検証タブ** で予想と結果を照合、自動学習が起動
4. 学習により次回の予想精度が向上

### 予測ロックの仕組み

- 抽選前日（日曜・水曜）の正午に予測が自動生成されます
- 生成後は抽選翌日まで番号がロック（固定）されます
- 「AI高度探索」ボタンでロック中でも1回だけ上書き可能

### バックテスト

- バックテストタブで「直近50回」「直近100回」をテスト
- 過去データに対して現在のアルゴリズムで予想を生成し直し、一致数を集計

## ホーム画面に追加

### iOS
Safari で開く → 共有ボタン → 「ホーム画面に追加」

### Android
Chrome で開く → メニュー → 「ホーム画面に追加」

## QRコードデータ同期

1. 設定タブ → 「QRコードを生成」
2. 別端末でQRコードを読み取り
3. 読み取ったJSONデータをインポート
